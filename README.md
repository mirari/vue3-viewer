## Installation / 安装

For Vue 3, install 5.x from the main package:

```sh
npm install v-viewer
```

The new major version includes breaking changes. Follow the current documentation when upgrading; the original examples apply to historical releases.

新版包含破坏性变更，请按当前文档升级，原有示例仅适用于历史版本。
